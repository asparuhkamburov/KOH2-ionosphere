# Migration notes from the operational 2023 script

The publication-oriented `process_koh2_pyoasis.py` was refactored from the
operational annual script while preserving its processing logic.

Main changes:

- removed hard-coded local paths;
- replaced fixed `YEAR = 2023` with `--year`;
- accepts a parent data root or annual root through `--data-root`;
- accepts the GFZRNX executable through `--gfzrnx` or `GFZRNX_PATH`;
- removed duplicated date/skip/output-folder blocks;
- split the workflow into testable functions;
- retained the original input-selection priority:
  1. `_01D_30S_MO`
  2. any `_30S_MO`
  3. `_01D_15S_MO`;
- retained GFZ rapid SP3 naming:
  `GFZ0MGXRAP_YYYYDDD0000_01D_05M_ORB.SP3.gz`;
- retained RINEX 2.x staging via GFZRNX `-vosc 2`;
- retained the pyOASIS processing sequence:
  `SP3intp -> RNXclean -> RNXlevelling -> ROTIcalc -> DTECcalc ->
  SIDXcalc -> TECcalc`;
- added a year-level processing summary and day-level exception handling.

Before calling this the final monograph release, compare outputs for several
known dates against the operational script.
