# KOH2 Solar Cycle figure suite

These scripts create publication-oriented figures from numerical products generated by the validated KOH2 analysis workflows.

## Scripts

- `01_plot_validation_benchmarks.py`
  - yearly PyTECGg/pyOASIS comparison with IGS Final GIM and Madrigal reference products;
  - writes `KOH2_validation_benchmark_plot_data.csv`.
- `02_plot_solar_reference_divergence.py`
  - strict-common-hour monthly inter-product differences with F10.7;
  - observed daily VTEC versus fitted F10.7 + seasonal background;
  - writes daily and monthly reference-difference CSV products.
- `03_plot_geomagnetic_response.py`
  - quiet/storm distributions;
  - within-year storm–quiet RMSE contrasts;
  - lagged geomagnetic Spearman-rho heatmap with bootstrap-robust results marked.
- `04_plot_multigim_and_coverage.py`
  - CODE/ESA/JPL/UPC multi-GIM comparison;
  - inter-method VTEC offset across selected GIM products;
  - year-by-month observation-day coverage heatmap.

## Interpretation

These scripts are downstream visualization/summary tools. Scientific claims should be based on the validated numerical analysis outputs rather than on rendering details.

- Madrigal is an external observation-derived GNSS TEC product; do not imply stronger independence than the data provenance supports.
- CODE/ESA/JPL/UPC constitute a multi-GIM/inter-product robustness comparison, not four independent validations.
- Geomagnetic results are described as associations or storm–quiet contrasts; the figures do not establish causality.
- PNG/PDF/SVG files are not expected to be bit-for-bit identical across Matplotlib versions or platforms.
